# MATRILINK Frontend Demo

面向 HR 与前端岗位沟通的工业官网演示仓库。站点源码位于 [`industry/`](industry/)，包含响应式中英文首页、产品目录和产品详情。

## 亮点

- 工业期刊式视觉系统与原创产品视觉
- 8 个虚构产品的搜索、分类和应用筛选
- 移动端筛选面板、产品快速详情抽屉与吸底 CTA
- 本地语言偏好、键盘操作、Reduced Motion 与前端表单校验
- 无数据库、无真实表单发送、无分析埋点

## 本地开发

```bash
cd industry
npm ci
npm run dev
```

需要 Node.js 22.13 或更高版本。
