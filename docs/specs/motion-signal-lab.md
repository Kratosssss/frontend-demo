# Motion Signal Lab 产品与动效设计规格

状态：**待用户人工审批**

设计方向：**Retro-futuristic Motion Signal Lab**

范围：纯静态展示页；本规格不决定作品集集成、构建或发布。

## 1. 产品目标与边界

### 产品目标

Motion Signal Lab 是一件单页前端动效作品，用可操作、可暂停、可降级的场景说明“动效是界面在时间维度里的排版”。页面要让招聘方或设计/前端同行在一次连续浏览中看懂以下能力：

1. 入场编排：用相位差建立阅读层级，而非同时显现所有元素。
2. 滚动编排：用 sticky 三幕保留对象连续性，表达 Enter → Connect → Resolve。
3. 空间响应：指针只影响舞台的轻量空间偏移，不阻碍阅读或滚动。
4. 微交互：Orbit、Pulse、Trace 三种逻辑可被用户明确切换并得到即时反馈。
5. 动态治理：全局暂停、键盘可用、系统 `prefers-reduced-motion` 降级与性能约束是作品本身的一部分。

### 目标受众

- 主要受众：快速评估前端表现力、交互判断与工程克制的招聘方、面试官。
- 次要受众：希望理解动效语法与实现边界的产品设计师、前端工程师。
- 核心浏览情境：桌面端 2–4 分钟完整浏览；移动端 1–2 分钟快速浏览。

### 成功标准

- 首屏 5 秒内同时传达“动效作品”“有目的的运动”“可以交互”。
- 用户无需说明即可找到滚动入口、全局暂停与三种动效模式。
- 任意时刻暂停或减少动态后，内容仍完整、顺序仍清楚、页面仍可正常滚动。
- 页面不依赖远程请求、后端、数据库、登录、埋点或生产数据。

### 非目标

- 不做通用动效编辑器、参数面板或可保存的实验工具。
- 不加入音频、视频、WebGL、3D 模型、鼠标拖拽、横向滚动或滚轮劫持。
- 不在本规格中决定入口卡片、路由、CloudBase 构建或发布方式。

## 2. 体验原则

1. **一个场景，一个主动作。** 背景动态只建立气氛，不与标题、对象或操作争夺注意力。
2. **输入与反馈相邻。** 指针、模式切换和暂停的结果在同一视区立即可见。
3. **连续而不黏滞。** 滚动驱动只读取页面自然进度，不锁定滚轮、不强制吸附。
4. **结束后退场。** 入场与状态切换均有明确静止终态，不以无限循环替代反馈。
5. **静态也是完整体验。** 暂停、系统减少动态、脚本不可用时都保留内容层级与可理解的终态。

## 3. 视觉系统

### 视觉语气

整体像一台被精密校准的未来信号仪器：深色实验室底、暖白文字、荧光信号色、细网格、坐标轴、遥测读数与编号。复古未来感来自排版、标尺和受控辉光，不使用厚重拟物控制台或高噪点赛博朋克装饰。

### 颜色令牌

| 用途 | 建议值 | 约束 |
| --- | --- | --- |
| 页面底色 `--ink-950` | `#08110F` | 主背景与浏览器主题色一致 |
| 抬升底色 `--ink-900` | `#0E1A17` | 舞台、sticky 场景与控制区 |
| 主文字 `--paper-100` | `#F0F2E8` | 深色背景上的标题与正文 |
| 次文字 `--paper-500` | `#9AA99F` | 标签、说明、遥测读数 |
| 主信号 `--signal-lime` | `#C7FF4A` | 当前状态、焦点、进度，不用于大段正文 |
| 次信号 `--signal-orange` | `#FF6B3D` | 关键节点或终幕太阳，每屏最多一处高饱和面 |
| 冷信号 `--signal-cyan` | `#67E8D1` | Trace 路径与辅助空间反馈 |
| 结构线 `--line` | `rgba(240,242,232,.18)` | 边框、网格、坐标轴 |

文本与背景对比至少 4.5:1；大号展示文字至少 3:1。荧光色不能成为状态的唯一识别方式，必须同时配合文案、形状、位置或 `aria-pressed`。

### 字体与排版

- 英文展示、数字与标签：本地 `IBMPlexSansCondensed-Regular.woff2`、`IBMPlexSansCondensed-SemiBold.woff2`。
- 中文与正文回退：`"PingFang SC", "Microsoft YaHei", system-ui, sans-serif`。IBM Plex Sans Condensed 不承担 CJK 字形。
- 字体必须 `font-display: swap`；预载仅限当前 HTML 已声明的两个 woff2 文件。
- Hero 标题：`clamp(4.6rem, 11vw, 10.5rem)`，行高 `.78–.84`，字距 `-.045em`。
- 章节标题：`clamp(2.4rem, 6vw, 6.2rem)`，行高 `.9–1.02`。
- 正文：桌面 18–20px、移动 16–18px，行高 1.6–1.75；标签 11–13px，字距 `.12–.18em`。

### 空间与表面

- 页面最大内容宽度 1440px；桌面左右安全边距 48–72px，平板 32px，移动 20px。
- 章节纵向留白桌面 144–200px，移动 88–120px。
- 结构以 12 列栅格为主；细线边框 1px，直角或 2–4px 微圆角。禁止卡片式大圆角和厚重阴影。
- 辉光只允许在 orbital core、当前模式与 finale sun 上使用；不使用大面积 `filter: blur()` 动画。

### 本地资产

必须提供：

- `motion-demo/fonts/IBMPlexSansCondensed-Regular.woff2`
- `motion-demo/fonts/IBMPlexSansCondensed-SemiBold.woff2`

不需要外部图片或图标库。轨道、网格、标尺、噪点、太阳和轨迹均由 CSS、现有内联 SVG 与 HTML 元素生成；不得新增远程字体、CDN 或运行时网络请求。

## 4. 页面叙事与信息层级

页面必须沿用 `motion-demo/index.html` 的现有内容顺序：

1. **全局状态层**：ambient field、scroll meter、header、暂停按钮，先声明这是一个“正在运行的序列”。
2. **Hero / Move with meaning**：用入场编排建立第一印象；右侧仪器舞台展示指针响应。
3. **Ticker**：短促换气，连接首屏与原则陈述。
4. **Manifesto / Motion grammar**：解释作品立场与 160–420ms、01 focus、0 noise 三个约束。
5. **Scroll Lab / 三幕 sticky**：主展项，依次演示 Enter、Connect、Resolve。
6. **Interaction Switchboard**：用户主动选择 Orbit、Pulse、Trace，证明动作可被控制且各有语义。
7. **Motion Discipline**：将表现力收束为 Purpose、Rhythm、Access 三条方法论。
8. **Finale**：以一次明确、非循环的太阳升起完成叙事，提供返回作品集的退出动作。

视觉权重从 Hero 与 Scroll Lab 两个高峰逐步下降；Principles 区不再引入新型动效，Finale 只做一次收束。

## 5. 全局动态状态机

### 状态

| 有效状态 | 根节点表现 | 用户可见文案 | 行为 |
| --- | --- | --- | --- |
| `running` | `html[data-motion="running"]` | `LIVE SEQUENCE` / `暂停动态` | 允许自主、指针、滚动插值和切换动效 |
| `paused` | `html[data-motion="paused"]` | `SEQUENCE PAUSED` / `继续动态` | 停止自主循环；交互与内容切换改为无过渡终态 |
| `reduced` | 系统 reduce 生效并反映到根节点 | `REDUCED MOTION` / `启用动态` | 默认静态完整态；不启动连续动画或插值 |

### 优先级与持久性

- 首次加载先读取 `prefers-reduced-motion`。为 `reduce` 时直接进入 `reduced`，不得先播放入场再切静态。
- 系统 preference 在会话中变化时立即生效；由 reduce 切回 no-preference 后进入 `paused`，不自动恢复运动。
- reduced 状态下，用户可通过明确激活按钮在当前页面会话中选择 `running`；这是一次有意的 opt-in，不在加载时自动发生。
- 用户暂停或 opt-in 仅在当前页面会话内有效，不写入 cookie、localStorage 或远端；系统 preference 再次变为 reduce 时应重新进入 `reduced`。
- `aria-pressed="true"` 表示“动态已暂停”；`running` 时为 `false`。状态文字与按钮标签必须同步更新。

### 暂停行为

- CSS 动画与过渡停止；JS 的时钟、指针插值、ticker 和自主循环停止。
- 页面滚动、锚点跳转、模式按钮与返回链接保持可用。
- 用户滚过 Scroll Lab 时仍即时切换当前幕的文字与终态画面，不播放跨幕插值，避免暂停导致内容失联。
- 重新继续时从当前滚动位置与当前模式恢复，不补播已错过的入场，也不发生位置跳跃。

## 6. 场景级动效规格

### 6.1 全局背景、Header 与 Scroll Meter

**目的**：建立“实时信号仪器”的环境并持续给出页面位置，不成为阅读任务。

- Ambient glow：24s 往返一次，位置总位移不超过视口宽高的 4%，透明度 `.12–.2`。
- Grain：静态纹理优先；若运动，仅用 8 帧 steps、12s 周期，整体不透明度不超过 `.045`。
- Grid：静态，不缩放、不闪烁。
- Scroll meter：基于 `scrollY / (scrollHeight - innerHeight)` 输出 000–100；视觉填充线性对应进度，数字取整。更新需走单个 `requestAnimationFrame`。
- Header 默认覆盖在页面顶端；桌面 sticky，移动保持普通 sticky 顶栏。背景在滚动后增加不透明底色，不做高成本实时模糊动画。
- 状态灯 running 时 1.8s 轻微呼吸；paused/reduced 时常亮或静止轮廓。

退出方式：全局暂停立即静止；页面失去可见性时停止所有循环，返回后按有效状态恢复。

### 6.2 Hero 入场编排

**目的**：证明时间差能够建立阅读顺序。用户第一眼应先读标题，再看说明，最后发现舞台与操作。

**触发**：DOM 可用且字体已可显示后的下一帧，仅播放一次；不等待全部字体下载。若系统 reduce 或用户在入场中暂停，立即落到完整终态。

| 相位 | 元素 | 起始状态 → 终态 | 延迟 | 时长 / 缓动 |
| --- | --- | --- | --- | --- |
| A | eyebrow 两段 | `opacity 0, y 12` → `1, 0` | 80ms，段间 60ms | 320ms / `cubic-bezier(.22,1,.36,1)` |
| B | Move / with / meaning. | 每行内层 `y 110%` → `0`，容器裁切 | 160ms，行间 90ms | 720ms / `cubic-bezier(.16,1,.3,1)` |
| C | intro 与进入链接 | `opacity 0, y 24` → `1, 0` | 500ms | 520ms / 同上 |
| D | hero stage | `opacity 0, scale .96, y 18` → `1,1,0` | 420ms | 680ms / 同上 |
| E | signal notes、readout | `opacity 0` → `1` | 740ms，项间 70ms | 360ms / ease-out |

总入场不超过 1.25s。标题稳定后不再循环移动。`进入滚动实验` 点击后自然滚到 `#scroll-lab`；running 可使用 520–700ms 平滑滚动，paused/reduced 必须立即跳转。

### 6.3 Hero 指针反馈与 Orbital System

**目的**：展示输入与空间反馈的直接关系，同时保持动作轻、可预测。

**触发与映射**：仅在 `(hover: hover) and (pointer: fine)` 且 running 时监听 `pointermove`。以舞台中心为 0，将输入归一化到 `[-1,1]`；离开舞台后 420ms 回到中心。

- stage frame：X/Y 位移上限分别 8px/6px；旋转上限分别 `rotateY(2.5deg)`、`rotateX(2deg)`。
- orbital core：反向位移上限 5px，形成景深但不改变可读文字位置。
- PTR 读数映射到 000–100，固定三位；读数 `aria-hidden`，不触发朗读。
- 平滑采用每帧向目标值收敛约 12–16%，不使用弹簧过冲。每帧只写 CSS 自定义属性，不重复读取布局。
- Outer orbit 12s、inner orbit 7.2s 线性循环且方向相反；节点不得闪烁。指针不改变轨道速度。

触屏、粗指针、paused 和 reduced：完全禁用指针追踪，保持居中终态。舞台不是操作控件，不增加 tabindex；对其能力的解释由 Hero 文案与 signal note 提供。

### 6.4 Signal Ticker

**目的**：作为章节分隔和节奏换气，不承载新信息。

- running：水平单向循环，18–22s 完成一组，复制文本确保无缝；速度约 45–60px/s。
- paused：停在当前位置；reduced：居中显示一组静态短语，超出裁切即可。
- `aria-hidden="true"` 保持不变，避免重复朗读。

### 6.5 Manifesto 与通用 Reveal

**目的**：用较慢、较少的 reveal 把视觉表演转为方法论。

- 进入视口 20% 时触发一次，默认 `opacity 0, y 32px` → `1,0`，520ms，`cubic-bezier(.22,1,.36,1)`。
- 同一组最多 3 项，间隔 80ms；不得逐字拆分中文正文。
- motion metrics 依次出现，数值先于解释 60ms；不做数字滚动。
- RHYTHM kinetic type 仅做一次 420ms 的字距收束，结束后静止。
- paused/reduced：初始即为终态，不通过 0.01ms 动画“模拟”静态。

### 6.6 Scroll Lab：sticky 三幕滚动

**目的**：用一个持续存在的对象证明滚动可以连接状态，而非切换三张互不相关的画面。这是全页主展项。

**空间模型**：

- 桌面与平板：外层高度约 300vh；sticky 容器 `top: 0`、高度 100svh。第 1/2/3 幕分别占归一化进度 `[0,.333)`、`[.333,.666)`、`[.666,1]`。
- 窄屏小于 768px：外层约 240svh，sticky 容器使用 `100svh`；文字在上、舞台在下，舞台高度不小于 38svh。若设备高度小于 620px，改为约 270svh 以免文字与舞台重叠。
- 不改变浏览器滚动方向、不强制 snap、不拦截 wheel/touchmove。通过 2% 滞后区防止阈值附近反复切幕。
- 当前幕数字、rail fill 与 `data-lab-progress` 同步；进度输出 000–100。

**对象连续性**：`sequence-stage__object` 在三幕中始终是同一个 DOM 对象；以 transform/opacity 改变状态，不替换节点。

| 幕 | 语义与视觉状态 | 幕内动作 | 进入/退出 |
| --- | --- | --- | --- |
| 01 ENTER | 对象从左下方进入中心附近；ghost A/B 展示错开的历史位置；ring 从 `.7` 收束到 `1` | 0–33% 内对象 x `-34% → 0`、y `22% → 0`，ghost 依次显现；文案强调“按相位进入” | 进入 420ms ease-out；临近 33% 时 ghost 降至 `.24`，不突然消失 |
| 02 CONNECT | path 与 axis 建立关联；对象沿路径移动到右上区域，satellite 与其保持方向关系 | 33–66% 内 path 用 stroke dashoffset 或裁切从 0→100%，对象同步沿预设 2D 路径；satellite 滞后 8–12% | 跨幕用连续进度，无缩放闪切；新文案 240ms 交叉淡化 |
| 03 RESOLVE | 对象抵达终点并稳定；ring 扩出一次确认，路径和 ghost 退为背景 | 66–86% 完成抵达；86–100% 保持静止终态。确认 ring 只触发一次，420ms 后消散 | 离开 sticky 后不得继续循环或突然复位；反向滚动按进度可逆 |

**文案状态**：只有当前 `.scene-copy` 可见并参与辅助技术树；切幕时先设置当前索引与 `aria-pressed` 等状态，再执行视觉过渡。`aria-live="polite"` 只在用户跨越幕阈值后更新一次，不随每帧进度朗读。快速跨过多幕时仅播报最终幕。

**暂停/减少动态**：

- paused：根据当前进度选择最近幕，立即显示该幕代表性终态；继续滚动可即时切幕，但不插值。
- reduced：取消 sticky，三篇 scene copy 按正常文档流依次展示；每篇配同一个舞台的静态快照或简化编号图，避免长达数屏的无动态留白。
- 键盘 PageUp/PageDown、Space、方向键和辅助技术滚动均依赖浏览器原生行为，不添加捕获快捷键。

### 6.7 Interaction Switchboard：Orbit / Pulse / Trace

**目的**：让用户主动比较三种运动逻辑的语义与节奏，而不只是观看预设序列。

**通用交互**：

- 三个 `.mode-button` 是原生按钮；点击、Enter、Space 均可选择。焦点不随选择自动移动。
- 可选增强：当焦点位于按钮组内时，Left/Right 或 Up/Down 移动焦点并选择相邻项，Home/End 到首尾；若实现，行为应符合单选组预期且不劫持组外按键。
- 选中后立即同步 `.is-active`、每个按钮的 `aria-pressed`、stage 的 `data-mode`、`data-mode-name`。可见反馈须在 100ms 内开始。
- 切换过渡总长 260–360ms：旧图 `opacity 1→0, scale 1→.96`，新图 `0→1, .96→1`；不同时运行两套高对比动画。
- 初始模式 Orbit；每次切换只播放所选模式，不持久化选择。

**Orbit / 连续方向**：

- 两个轨道分别 6.4s 与 9.6s 线性循环，方向相反；节点始终可辨识方向。
- 核心 O 静止，避免整个画面一起转导致眩晕。
- 退出时在当前角度淡出；重返可从零开始，不需要保存相位。

**Pulse / 强调反馈**：

- 选择时核心先 180ms 从 `.92→1`，随后三圈每隔 140ms 向外扩散；单轮 1.4s。
- running 下可每 2.8s 重复一次，轮间至少 1.4s 完全静止；不得持续闪烁或改变背景亮度。
- 圆环透明度从 `.55→0`，不能用大面积白色闪光。

**Trace / 路径关联**：

- 路径在 1.6s 内由左至右绘出，节点用同一归一化进度沿路径移动；缓动 `cubic-bezier(.65,0,.35,1)`。
- 到终点停留 900ms，再以 320ms 淡出后重启；不反向扫回。
- SVG path 是表现层，保持 `aria-hidden`; `ACTIVE LOGIC` 文案负责传达当前逻辑。

**paused/reduced**：选择仍有效，但直接显示该模式最清楚的静态终态：Orbit 显示错位节点、Pulse 显示三圈不同半径、Trace 显示完整路径与终点。不得因暂停而禁用按钮。

### 6.8 Principles 与 Finale

**目的**：从展示回到判断标准，并给用户明确离场。

- Principles 三项在视口内按 90ms 间隔做一次 480ms 上移淡入；hover 只允许边线/编号颜色 160ms 变化，不移动整行。
- Finale 标题按行 70ms 错开出现，总时长不超过 760ms。
- finale sun 从 `translateY(22%) scale(.92)` 到静止终态，900ms，`cubic-bezier(.16,1,.3,1)`；仅播放一次，无呼吸循环。
- 返回链接 hover/focus：箭头 x `0→6px`，160ms；paused/reduced 仅改变颜色/下划线，不位移。

## 7. 响应式行为

### 桌面 `>= 1024px`

- Hero 使用 12 列，两侧约 7/5 或 6/6 分配；标题与舞台可并列但不得互相覆盖。
- Scroll Lab 文案约 5 列、舞台约 6 列，scene rail 位于外侧。
- Switchboard 选择器与舞台并排；指针反馈启用条件仍以输入能力查询为准，而非仅看宽度。

### 平板 `768–1023px`

- Hero 可保持两列但缩小标题，舞台最小宽 320px；空间不足时转为上下布局。
- Scroll Lab 继续 sticky，文案与舞台 5/7 分配或上下压缩排列；所有状态文字保持可见。
- Mode selector 可三列等宽，stage 独占下一行。

### 移动 `< 768px`

- 单列顺序严格跟随 DOM；Hero 先标题/说明，后舞台。舞台宽 100%，最小高度 320px。
- Header 允许品牌名称在极窄屏隐藏，但保留 `M/06`、状态和至少 44×44px 的暂停按钮。
- Scroll meter 简化为顶部 2px 进度线与三位数字；隐藏竖排 side note 和非必要遥测，不隐藏核心说明。
- Mode selector 纵向堆叠；按钮高度至少 56px，舞台高度 300–380px。
- 指针视差、依赖 hover 的反馈全部关闭；触摸不会触发伪 hover 粘滞状态。

### 极窄与横屏

- 支持 320px CSS 宽度，不出现页面级横向滚动。
- 高度不足 620px 时 header、scroll lab 与舞台以 `svh` 计算，确保地址栏变化不造成跳跃；必要时允许内容在 sticky 内部缩排，但不允许内部滚动容器抢夺主滚动。

## 8. 键盘、无障碍与降级

### 结构与焦点

- 保留 skip link；聚焦时必须在视口内清晰显示，跳到 `#main-content` 后标题区域可被定位但不强制焦点陷阱。
- 保持一个 `h1` 与顺序正确的 `h2`/`h3`。装饰网格、轨道、ticker、遥测和太阳继续 `aria-hidden="true"`。
- 所有按钮与链接的焦点指示至少 2px，颜色对比至少 3:1，不能只依赖背景变色。
- 交互目标最小 44×44 CSS px；焦点顺序按 DOM：品牌/暂停 → 滚动入口 → 模式按钮 → 返回链接。
- 动效不应移动当前焦点元素，也不得自动聚焦或自动滚动。

### 动态内容

- Scroll Lab 每次跨幕最多产生一次 polite announcement；持续进度、时钟和指针坐标不进入可访问名称或 live region。
- 模式按钮通过自身 `aria-pressed` 反馈选择，caption 同步可见文案；不得额外重复播报动画帧。
- 暂停按钮的可访问名称描述下一步动作：running 为“暂停动态”，paused 为“继续动态”，reduced 为“启用动态”；reduced 下只有用户明确激活才启动动态。

### `prefers-reduced-motion` 降级矩阵

| 模块 | running | reduced |
| --- | --- | --- |
| Hero | 一次性相位入场 + 轨道循环 | 内容首帧完整可见；轨道静态 |
| 指针舞台 | 细指针视差 + PTR 更新 | 居中静态；不监听 pointermove |
| Ticker / ambient | 低速循环 | 静态短语 / 静态纹理 |
| Scroll Lab | sticky 连续三幕 | 取消 sticky，三幕正常文档流静态展示 |
| Mode stage | 选中模式循环或重播 | 按钮可选；对应静态终态 |
| Reveal / Finale | 一次性过渡 | 直接呈现终态，无延迟 |
| 锚点 | 平滑滚动 | 浏览器即时跳转 |

不得把所有 duration 粗暴设为 `0.01ms` 作为唯一方案；JS 必须在启动监听与循环前识别 reduce，CSS 也要提供独立静态终态。

### 脚本不可用

- 核心标题、正文、三幕文案、原则与离场链接必须可阅读；CSS 只能在确认 JS 状态后隐藏非当前内容。
- 若交互脚本未加载，所有内容保持正常文档流或完整终态，不能因初始 `opacity: 0` 形成空白页面。

## 9. 性能边界

- 动画属性以 `transform`、`opacity`、SVG `stroke-dashoffset` 和少量 CSS 自定义属性为主；禁止动画 `width/height/top/left` 导致持续布局。
- 全页最多一个 scroll rAF、一个 pointer rAF；同帧先读后写。scroll/pointer 监听使用 passive，resize 使用节流或 ResizeObserver。
- 不在每帧调用 `getBoundingClientRect()`；Scroll Lab 的起止边界只在进入、resize 或布局变化后重新测量。
- 离开视口的非全局场景停止自主循环；`document.hidden` 时全部暂停。恢复时不追赶时间。
- `will-change` 只加在当前运动的少量元素上，结束后移除；避免给网格、所有文字或整页常驻提升层。
- 不引入第三方动效库；目标为现代中端移动设备滚动时无明显主线程卡顿，单次输入反馈在 100ms 内开始。
- 两个本地字体文件合计建议不超过 180KB；除字体外不新增二进制资产。首屏脚本解析不阻塞 HTML。
- 视觉回归需覆盖 1440×900、1024×768、390×844、320×568，并验证浏览器 200% 缩放时无内容遮挡。
